## 1. 자물쇠 계열

### 숫자 자물쇠
- **묘사:** 3~4자리 숫자 입력
- **단서 예시:** 방 곳곳에 흩어진 숫자들 (그림 액자 번호, 책 쪽수, 시계 시간)
- **Godot 구현:** `LineEdit` + `text_submitted` 시그널 → 정답 비교
- **초보 추천도:** ★★★

### 방향 자물쇠
- **묘사:** 상/하/좌/우 방향 4~6개 조합
- **단서 예시:** 화살표 그림, 발자국 방향
- **Godot 구현:** `Button` 4개 + 입력 배열 → 정답 배열 비교
- **초보 추천도:** ★★★

### 색상 자물쇠
- **묘사:** 색상 조합 (3~4색)
- **단서 예시:** 그림의 색 순서, 창문으로 들어오는 빛 색깔
- **Godot 구현:** `ColorRect` 배열 클릭으로 색 변경 → 정답 배열 비교
- **초보 추천도:** ★★

## 2. 조합 계열

### 아이템 조합
- **묘사:** 인벤토리 두 아이템을 합쳐 새 아이템 생성
- **예시:** 빈 컵 + 물 → 물이 담긴 컵
- **Godot 구현:** 인벤토리에서 아이템 A를 아이템 B에 드래그 또는 "사용" → 조합 레시피 딕셔너리 확인
- **초보 추천도:** ★★

### 기계 작동
- **묘사:** 부품을 제자리에 놓으면 기계 작동
- **예시:** 톱니바퀴 3개를 빈 자리에 놓으면 문 열림
- **Godot 구현:** `Area2D` 드롭 영역 + 올바른 아이템 드롭 감지
- **초보 추천도:** ★ (드래그앤드롭 구현 복잡)

---

## 3. 암호/해독 계열

### 치환 암호
- **묘사:** 그림/기호 → 알파벳/숫자 변환
- **예시:** 벽에 붙은 표: ★=1, ♦=2, ♣=3 → 그림 열쇠에 ★♦♣ = 123
- **Godot 구현:** `LineEdit` 입력 + 정답 비교 (단순)
- **초보 추천도:** ★★★

### 뒤집힌 텍스트
- **묘사:** 거울에 비친 글씨 읽기
- **Godot 구현:** `Label` + `scale.x = -1` (미러 효과)
- **초보 추천도:** ★★★

### 책/일기 단서
- **묘사:** 텍스트에서 키워드 조합
- **예시:** 일기 "3월의 첫날, 7층 창가에서..." → 317 또는 37
- **Godot 구현:** `RichTextLabel` 팝업
- **초보 추천도:** ★★★

## 4. 환경 조작 계열

### 순서 기억
- **묘사:** 깜빡이는 순서 기억 후 재현
- **Godot 구현:** `Timer` + 배열 순서 애니메이션 → 입력 배열 비교
- **초보 추천도:** ★ (복잡)

### 조명 조작
- **묘사:** 특정 조명 조합으로 패턴 만들기
- **Godot 구현:** `Light2D` on/off 토글
- **초보 추천도:** ★★

---

## 5. 인벤토리 활용 계열

### 열쇠-자물쇠
- **묘사:** 열쇠 아이템 → 잠긴 오브젝트 사용
- **Godot 구현:** 인벤토리에 해당 아이템 있는지 확인 → `GameState` 업데이트
- **초보 추천도:** ★★★

### 도구 사용
- **묘사:** 특정 도구로 오브젝트 조작 (드라이버로 나사 풀기)
- **Godot 구현:** 활성 아이템 선택 + 오브젝트 클릭 시 아이템 타입 확인
- **초보 추천도:** ★★
