# 퇴근 승인 바랍니다 — Game Design Document

**엔진:** Godot 4.x (GDScript)  
**장르:** 방탈출 싱글플레이어 (텍스트+이미지 퍼즐 혼합)  
**예상 플레이 시간:** 40~50분  
**엔딩:** 6종

---

## 1. 핵심 컨셉

> 회사 = 방탈출 맵 / 업무 = 퍼즐 / 퇴근 = 탈출

플레이어는 오늘 중으로 퇴근 승인을 받아야 한다. 퍼즐을 어떻게 푸느냐(정석/꼼수/반항)가 엔딩을 결정한다.

---

## 2. 상태 변수 (GameState 싱글턴에 저장)

| 변수 | 초기값 | 변화 방식 | 엔딩 영향 |
|------|------|---------|---------|
| `accuracy` | 0 | 퍼즐 정석 풀이 +1, 오답 -1 | 높음 → 정상/완벽 퇴근 |
| `stress` | 0 | 퍼즐 실패/야근 이벤트 +1 | 7 이상 → 야근 엔딩 위험 |
| `resistance` | 0 | 반항 선택지 +1 | 7 이상 → 칼퇴/퇴사 엔딩 |
| `conformity` | 0 | 순응 선택지 +1 | 10 이상 → 회사의 일부 엔딩 |
| `overtime_flag` | 0 | 시간 초과/야근 선택 +1 | 3 이상 → 야근 엔딩 |
| `hidden_clues` | [] | 히든 메시지 수집 시 추가 | 4개 이상 → 히든 루트 해금 |
| `time_remaining` | 60분 | 퍼즐 실패 시 -3분 | 0 → 야근 엔딩 |

## 4. 퍼즐 10개 상세 명세

### 퍼즐 1: 출근 기록 확인
- **위치:** 사무실 → 컴퓨터
- **유형:** 숫자 입력 (4자리)
- **상황:** 출근 시스템에 `08:??` 오류
- **단서 위치:**
  | 단서 | 위치 | 시간 |
  |------|------|------|
  | 커피 영수증 | 책상 위 | 08:42 |
  | 엘리베이터 로그 | 서랍 속 문서 | 08:47 |
  | 보안게이트 기록 | 컴퓨터 파일 | 08:49 |
  | 메신저 첫 메시지 | 메신저 앱 | 08:53 |
- **정답:** `0849` (보안게이트 기준 = 회사 공식 출근 기준)
- **풀이 분기:**
  - `0849` → accuracy +1
  - `0842` → accuracy -1, resistance +1
  - 버튼 5회 클릭(반항) → 히든 메시지 1 획득
- **Godot 구현:** `LineEdit` + `submit_button` → 정답 비교 → GameState 업데이트

---

### 퍼즐 2: 메일 정리
- **위치:** 사무실 → 컴퓨터 → 메일함
- **유형:** 분류 선택 (중요/일반/스팸)
- **상황:** 메일 20개 수신. 5개 핵심 메일 분류
- **핵심 메일:**
  | 메일 | 올바른 분류 |
  |------|---------|
  | 거래처 확인 요청 | 중요 |
  | 퇴근 승인 공지 | 중요 |
  | 보안 업데이트 | 중요 |
  | 부장님 전달 사항 | 중요 |
  | IT팀 공지 | 중요 |
- **함정 메일:** "급함!!!" → 스팸 / "긴급회의 17:30" → 일반(참석자 없음)
- **클리어 조건:** 5개 중 4개 이상 정확 분류
- **보상:** 일정표 아이템 획득, 퍼즐 3 해금
- **반항 처리:** 전체 읽음 처리 → 히든 메일 해금
- **Godot 구현:** 메일 리스트 UI (`VBoxContainer`) + 각 메일 클릭 시 분류 팝업

---

### 퍼즐 3: 회의 일정 맞추기
- **위치:** 회의실
- **유형:** 이미지 퍼즐 (도형/시간 선택)
- **상황:** 팀원 4명 일정 겹침 찾기
- **함정:** 17:30 = 자동 야근 처리 규정
- **정답:** 17:00
- **반항:** 회의 거부 → "메일 대체" → resistance +1, hidden_clues 추가
- **Godot 구현:** 일정표 이미지 + 클릭 가능한 시간 슬롯

---

### 퍼즐 4: 상사 지시 해석
- **위치:** 사무실 (여러 단서 탐색)
- **유형:** 조사 + 선택지
- **상황:** "그거 적당히 알아서 빨리 처리해"
- **단서:**
  | 단서 | 위치 |
  |------|------|
  | "A안은 절대 제출 금지" | 책상 포스트잇 |
  | 보고서_B_수정.docx | 컴퓨터 공유폴더 |
  | 3분기 수치 | 회의실 화이트보드 |
  | 이전 메일 히스토리 | 메일함 |
- **정답:** 보고서_B_수정 → PDF 변환 → 3분기 수치 반영 → 제출
- **반항:** 인사팀 문의 → 히든 메시지 2 획득
- **Godot 구현:** 탐색 클릭 → 메모 팝업 → 최종 선택지 4개 제시

---

### 퍼즐 5: 엑셀 매출 계산
- **위치:** 사무실 → 컴퓨터
- **유형:** 이미지 퍼즐 (그래프/표 읽기)
- **조건:** 05/01~05/02 + 상태=완료 + 부서=영업1팀 합계
- **정답:** 120 + 250 = 370 → 코드 `0370`
- **함정:** 숨겨진 시트 `ANSWER_DO_NOT_OPEN`에 답 노출 (꼼수 루트)
- **반항:** 수식에 `=퇴근()` 입력 → 에러 메시지 표시
- **Godot 구현:** 스프레드시트 이미지 + LineEdit 입력

---

### 퍼즐 6: 복사기 고장
- **위치:** 복사실
- **유형:** 이미지 퍼즐 (순서 클릭)
- **오류:** `ERROR 404: PAPER NOT FOUND` (용지는 있음)
- **정답 순서:** 토너함 열기 → 관리자 버튼 → 급지함 닫기 → 초록 버튼 → 빨간 버튼
- **실패 패널티:** 전원 버튼 -3분, 급지함 먼저 -2분
- **히든:** 3회 실패 시 로그 출력 → B1 비상구 단서
- **Godot 구현:** 복사기 이미지 + 클릭 가능한 버튼들 (`Area2D`) + 순서 배열 비교

---

### 퍼즐 7: 결재 라인 맞추기
- **위치:** 사무실 → 결재 시스템
- **유형:** 이미지 퍼즐 (도형 연결)
- **조건:** 금액 80만원 + 퇴근 승인 관련
- **규정 단서:**
  - 100만원 미만 → 팀장 전결
  - 퇴근 관련 → 인사팀 확인 필수
- **정답:** 팀장 → 인사팀
- **반항:** 결재자에 본인 이름 → 권한순환 오류 메시지
- **Godot 구현:** 결재 흐름도 이미지 + 드래그 또는 버튼 선택

---

### 퍼즐 8: 탕비실 암호
- **위치:** 탕비실
- **유형:** 관찰 + 숫자 입력
- **단서:** 재고표 감소량 (종이컵 6 / 믹스커피 3 / 아메리카노 2 / 녹차 1)
- **정답:** 감소량 순서 → `4213` (4번째/2번째/1번째/3번째 순위)
- **히든:** 냉장고 뒤 메모 → 비상계단 카드키 획득
- **Godot 구현:** 탕비실 배경 이미지 + 재고표 클릭 팝업 + 냉장고 클릭 히든

---

### 퍼즐 9: 퇴근 승인 시스템
- **위치:** 사무실 → 컴퓨터 → 퇴근 시스템
- **유형:** UI 퍼즐 (체크박스 조작)
- **함정:** 체크 시마다 새 업무 생성 (무한루프)
- **해결:** 체크박스 이름 첫 글자 조합 = "오늘은퇴근하라" → 해당 항목만 체크
- **정답 체크:** "퇴근 승인", "근무 종료 보고"
- **반항:** 시스템 로그 `loop=true` → `loop=false` 변경 → 퇴사 엔딩 해금
- **Godot 구현:** `CheckBox` 배열 + 동적 업무 생성 로직 + 로그 뷰어

---

### 퍼즐 10: 야근 유도 대화 회피
- **위치:** 사무실 출구 앞
- **유형:** 선택지 대화
- **상황:** 퇴근 직전 "잠깐 시간 괜찮아?"
- **선택지:**
  | 선택 | 결과 |
  |------|------|
  | "네, 괜찮습니다." | overtime_flag +1 → 야근 |
  | "내일 오전에 바로 확인하겠습니다." | 최선 → 정상 퇴근 |
  | "죄송합니다. 지금은 어렵습니다." | resistance +1 → 반항 증가 |
- **Godot 구현:** 대화 팝업 + 선택지 버튼 3개

## 5. 히든 루트: 비상계단

**해금 조건:** `hidden_clues` 배열에 4개 이상 수집 + `card_key` 인벤토리 보유

히든 메시지 수집처:
| 번호 | 메시지 | 획득 방법 |
|------|------|---------|
| 1 | "퇴근은 승인받는 것이 아니다." | 퍼즐1 버튼 5회 클릭 |
| 2 | "불명확한 지시는 권력이 아니라 오류다." | 퍼즐4 인사팀 문의 |
| 3 | "반복은 시스템의 실패다." | 퍼즐6 3회 실패 로그 |
| 4 | "책상은 감옥의 가장 작은 형태다." | 포스트잇 뒷면 |
| 5 | "퇴근하고 싶다면 냉장고 뒤를 봐." | 탕비실 냉장고 |

비상계단 최종 선택:
- 회사 밖으로 나간다 → 칼퇴 엔딩
- 자리로 복귀한다 → 회사의 일부 엔딩
- 시스템 종료 버튼 누른다 → 퇴사 엔딩

## 6. 엔딩 6종

| 엔딩 | 조건 | 마지막 텍스트 |
|------|------|------------|
| 완벽한 직원 | accuracy≥15, resistance≤2, conformity≥5 | "내일 08:50 회의가 등록되었습니다." |
| 정상 퇴근 | accuracy≥10, stress<7, resistance 3~6 | "평범한 저녁이 시작되었다." |
| 야근 | overtime_flag≥3 또는 시간 초과 | "조금만 더 하면 끝납니다." |
| 칼퇴 (히든) | resistance≥7, 카드키 보유, hidden_clues≥3 | "생각보다 문은 쉽게 열렸다." |
| 퇴사 (히든) | resistance≥10, 시스템 로그 조작 성공 | "승인은 필요 없었다." |
| 회사의 일부 | conformity≥10, resistance≤1 | "플레이어가 NPC 직원이 되었습니다." |

## 8. 기술 요구사항 (Godot 4.x)

| 시스템 | 구현 방법 |
|--------|---------|
| 상태 변수 관리 | `GameState` Autoload 싱글턴 |
| 씬 전환 | `get_tree().change_scene_to_file()` |
| 인벤토리 | `GameState.inventory: Array[String]` |
| 타이머 | `GameState.time_remaining` + `Timer` 노드 |
| 퍼즐 상태 | `GameState.puzzle_states: Dictionary` |
| 저장/불러오기 | `FileAccess` + JSON |
| 대화/선택지 | `Panel` + `VBoxContainer` + `Button` 배열 |
| 이미지 퍼즐 | `TextureRect` + `Area2D` 클릭 감지 |

## 9. MVP 범위 권장

전체 구현은 복잡하므로 단계적 접근 권장.

### MVP (v1.0) — 먼저 이것만
- 씬 3개: 사무실, 복사실, 엔딩
- 퍼즐 3개: 출근기록(1), 복사기(6), 야근회피(10)
- 상태 변수: accuracy, resistance만
- 엔딩 2개: 정상 퇴근, 야근
- 인벤토리 없음 (단순화)

### v1.5 — 확장
- 퍼즐 추가: 메일 정리(2), 결재 라인(7), 퇴근 시스템(9)
- 씬 추가: 탕비실, 회의실
- 상태 변수 전체
- 엔딩 4개

### v2.0 — 완성
- 전체 퍼즐 10개
- 히든 루트 + 비상계단
- 6종 엔딩
- 저장/불러오기
