# 퇴근 승인 바랍니다 — UI/UX 디자인 명세

**대상 엔진:** Godot 4.x  
**해상도 기준:** 1920 × 1080 (16:9), 최소 지원 1280 × 720

---

## 1. 전체 분위기 및 컨셉

### 톤: 지친 현실 + 블랙코미디

"밝지도, 어둡지도 않은 회사의 기본값" — 형광등 아래 사무실의 그 특유한 회색빛 피로감.
직장인이 즉각 공감할 수 있는 시각 언어를 쓰되, 게임적 과장과 블랙유머로 숨통을 튼다.

### 시각적 키워드 5개

| 키워드 | 설명 |
|--------|------|
| **회색의 격식** | 공공기관 같은 무채색 기반. 감정을 억누른 듯한 깔끔함 |
| **형광등 피로** | 약간 과포화된 흰색 영역, 눈에 살짝 피로한 밝기 |
| **오래된 UI** | Windows 2000 ~ XP 시대 사내 인트라넷 느낌. 볼드 테두리, 베이지 계열 배경 |
| **은밀한 레드** | 경고·금지·스트레스 요소에만 빨간색이 튀어나옴 |
| **히든의 어둠** | 히든 루트 진입 시에만 전체 톤이 어두운 필름누아르로 반전 |

### 참조 무드

- 사내 인트라넷 화면 그 자체 (그리드 테이블, 박스 테두리, 회색 버튼)
- 레트로 오피스 소프트웨어 (한글과컴퓨터 구버전, Excel 2003)
- 밤 야근 중 혼자 켜진 모니터 — 공포는 아닌데 뭔가 쓸쓸한 빛

## 3. 폰트 방향

### 기본 원칙

- **모든 폰트는 한글 지원 필수**
- 웹폰트 의존 없이 Godot 프로젝트에 `.ttf` / `.otf` 파일로 임베드
- "사내 공문서 느낌" + "레트로 인트라넷 느낌"을 동시에 충족

### 추천 폰트 (무료/오픈소스)

| 용도 | 추천 폰트 | 대체 폰트 | 스타일 |
|------|---------|---------|------|
| **헤드라인** | 나눔바른고딕 Bold | 본고딕 Bold | 고딕 계열, 무게감 있는 산세리프 |
| **본문 / 대화** | 나눔고딕 Regular | 노토산스KR Regular | 읽기 편한 중간 굵기 |
| **UI 레이블 / 버튼** | 나눔바른고딕 Regular | 나눔스퀘어 Regular | 작은 크기에서도 명확히 읽힘 |
| **코드 / 시스템 로그** | D2Coding | JetBrains Mono | 등폭 폰트 — 인트라넷 로그창 느낌 |
| **오류 메시지 / 경고** | 나눔바른고딕 Bold | - | 위와 동일, 적색 적용 |

### 사이즈 체계

| 등급 | 크기 (1920×1080 기준) | 용도 |
|------|---------------------|------|
| Display | 48px | 엔딩 화면 메인 텍스트 |
| Headline | 32px | 씬 타이틀, 팝업 제목 |
| Subhead | 22px | 섹션 제목, 중요 UI 레이블 |
| Body | 18px | 대화문, 설명 텍스트 |

| Micro | 11px | 상태바 수치, 타이머 |

## 4. 씬별 배경 분위기

### 4-1. 사무실 (office.tscn) — 게임의 기준점

**색감:** `#F0EFEA` 바닥 + 형광등 흰빛 천장. 창문은 흐릿한 외부 빛.  
**조명:** 균일한 형광등. 그림자 거의 없음 — 숨을 곳 없는 느낌.  
**소품 배치 방향:**
- 책상은 격자로 배열, 각 책상에 모니터 1대씩
- 모니터 화면은 항상 켜진 상태 (인트라넷 화면 표시)
- 책상 위: 커피잔, 서류 더미, 포스트잇 쪽지 (클릭 가능 요소 시각화)
- 벽면: 게시판 (공지사항), 시계 (타이머 연동)
- 배경 인물: 흐릿한 실루엣 NPC 2~3명 (상호작용 없음, 분위기용)

**핵심 시각 언어:** "아무도 특별하지 않은 곳" — 무채색, 반복적 패턴

---

### 4-2. 회의실 (meeting_room.tscn) — 공식적 압박감

**색감:** 벽면에 `#3A5F8A` 계열 진한 파란 라인이 들어간 회색.  
**조명:** 약간 어두운 조도 + 화이트보드 반사광.  
**소품 배치 방향:**
- 긴 테이블 가운데 배치, 의자 여러 개
- 화이트보드 (클릭 가능 — 퍼즐 3 단서)
- 빔프로젝터 스크린 (꺼진 상태, 위협적 느낌)
- 각 자리에 명패 없이 빈 노트패드만

**핵심 시각 언어:** "결정이 이루어지는 척 하는 곳" — 어색한 공식성

---

### 4-3. 복사실 (copy_room.tscn) — 고립감과 기계적 좌절

**색감:** 콘크리트 회색 + 종이 베이지.  
**조명:** 창문 없음, 형광등 1개가 깜빡이는 듯한 느낌 (깜빡임 애니메이션 추천).  
**소품 배치 방향:**
- 복사기 중앙 배치 (큼직하게, 인터랙션 오브젝트의 왕)
- 바닥에 종이 몇 장 흩어져 있음
- 선반에 복사기 매뉴얼 바인더 (클릭 가능)
- 에러 코드가 깜빡이는 작은 LED 패널 (빨간색)

**핵심 시각 언어:** "아무도 없고, 기계도 안 되고" — 고립된 좌절

---

### 4-4. 탕비실 (break_room.tscn) — 유일한 따뜻함 (역설)

**색감:** `#D4A017` 계열의 노란 형광등 빛, 벽면은 크림색.  
**조명:** 다른 씬보다 따뜻한 색온도. 단 창문은 없거나 매우 작음.  
**소품 배치 방향:**
- 냉장고 (클릭 가능 — 히든 단서 보관)
- 재고표 종이 (클릭 가능 — 퍼즐 8 단서)
- 전자레인지, 커피 머신, 종이컵 디스펜서
- 냉장고에 마그넷으로 붙은 낙서 ("퇴근하고 싶다")

**핵심 시각 언어:** "도망처럼 오는 곳, 근데 여기도 회사다" — 가짜 해방감

---

### 4-5. 비상계단 (hidden_staircase.tscn) — 히든 루트 전용

**색감:** 거의 무채색에 가까운 어두운 청회색. 야광 비상구 표지 초록만 반짝임.  
**조명:** 비상등 1개 (빨간색 약한 점멸). 계단 아래는 보이지 않음.  
**소품 배치 방향:**
- 녹슨 철문, 비상구 표지
- 벽에 낙서 (히든 메시지 5 텍스트가 여기 물리적으로 적혀 있음)
- 계단 끝에 빛 (출구 암시)

**핵심 시각 언어:** "진짜가 여기 있다" — 전환점의 연출

## 5. HUD 디자인 방향

### 5-1. 레이아웃 와이어프레임

```
┌─────────────────────────────────────────────────────────────────┐
│ [현재 시각: 17:42]      [잔여시간 게이지]        [S:2 A:3 R:1] │  ← 상단 HUD 바
│                                                                 │
│                                                                 │
│                       [ 게임 씬 영역 ]                          │
│                                                                 │
│                                                                 │
│                                                            [인벤] │  ← 우하단 인벤토리 버튼
└─────────────────────────────────────────────────────────────────┘
```

### 5-2. 상단 HUD 바 스타일

- **형태:** 화면 상단 고정 바. 높이 48px.
- **배경:** `#2C2C2C` (모니터 색). 하단 경계선 `#3A5F8A` 1px.
- **좌측:** 현재 시각 표시 ("오후 5:42" 형식, D2Coding 폰트 14px)
- **중앙:** 잔여시간 게이지
- **우측:** 상태 아이콘 3개 (스트레스 / 정확도 / 저항도)
- **전체 컨셉:** 사내 인트라넷 상단 네비게이션 바 느낌

### 5-3. 잔여시간 게이지 표현 방식

```
오후 5:00 ████████████████████░░░░░░ 오후 6:00
          ↑                          ↑
        시작                        야근 기준
```

- **형태:** 가로 Progress Bar. 배경은 어두운 그레이, 충전 색은 `#3A5F8A`.
- **60분 → 0분** 감소 방향이 아닌, "현재 몇 시인지"를 표시하는 타임라인 방식.
- **50분 이하** (오후 5:50 기준): 게이지 색이 `#D4A017` 으로 전환 (노란 경고).
- **30분 이하** (오후 5:30 기준): `#C0392B` 붉은색으로 전환 + 미세 진동 애니메이션.
- **게이지 위 마이크로 텍스트:** "퇴근까지 N분" (D2Coding 11px, 흰색).
- 퍼즐 실패로 -3분 발생 시: 게이지가 순간 빨간 플래시 후 뒤로 점프.

### 5-4. 상태 아이콘 처리

| 아이콘 | 표현 | 표시 기준 |
|--------|------|---------|
| S (스트레스) | 빨간 숫자 + 두통 아이콘 | stress ≥ 3 시 빨간색 |
| A (정확도) | 파란 숫자 + 체크 아이콘 | accuracy ≥ 5 시 강조 |
| R (저항도) | 노란 숫자 + 주먹 아이콘 | resistance ≥ 5 시 노란색 |

- **아이콘 크기:** 24×24px, 터치영역 44×44px
- **기본 숨김:** 0인 상태는 아이콘 흐리게 처리 (비활성 느낌)
- **블랙코미디 포인트:** stress가 7 이상이면 아이콘 옆에 미세하게 "..." 말풍선 출현

## 6. 인벤토리 UI

### 6-1. 인벤토리 버튼 (우하단 고정)

```
┌──────┐
│ 가방  │  ← 44×44px 이상 버튼
│  [N] │  ← 아이템 개수 뱃지
└──────┘
```

- 위치: 화면 우하단, 마진 16px.
- 스타일: 두꺼운 테두리의 회색 버튼. "서류가방" 아이콘.
- 아이템 수 뱃지: `#C0392B` 원형, 흰 숫자. 0개면 뱃지 숨김.

### 6-2. 인벤토리 팝업

```
┌─────────────────────────────────────┐
│  [ 소지품 목록 ]              [닫기] │
├─────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │ 일정표│ │보안기 │ │카드키│        │
│  │ 📄  │ │ 록  │ │  🔑  │        │
│  └──────┘ └──────┘ └──────┘        │
│                                     │
│  ┌──────┐ ┌──────┐                  │
│  │매뉴얼 │ │히든1  │                  │
│  │      │ │  ⚠  │                  │
│  └──────┘ └──────┘                  │
│                                     │
├─────────────────────────────────────┤
│  [선택된 아이템 설명 텍스트 영역]     │
└─────────────────────────────────────┘
```

- **팝업 크기:** 560×420px (1920×1080 기준)
- **배경:** `#F0EFEA`, 테두리 `#8A8F99` 2px solid
- **제목 바:** `#2C2C2C` 배경, 흰 텍스트 "소지품 목록" (사내 시스템 창 제목 스타일)
- **아이템 슬롯:** 80×80px, 테두리 `#8A8F99` 1px, 내부 `#FFFFFF`
  - 빈 슬롯: 점선 테두리, 내부 흐릿한 회색
  - 아이콘: 단색 플랫 일러스트 (색상은 오피스 그레이 계열)
  - 히든 아이템 슬롯: 테두리 `#D4A017` 황색 점선, 아이콘 어둡게 처리
- **선택 상태:** 슬롯 배경 `#3A5F8A` 15% 오버레이 + 테두리 파란색
- **설명 영역:** 슬롯 클릭 시 하단 텍스트 박스에 아이템 설명 표시 (나눔고딕 18px)
- **닫기 버튼:** 우상단 "×" 버튼, 44×44px

## 7. 퍼즐 UI 공통 스타일

### 7-1. 퍼즐 팝업 프레임

```
┌═══════════════════════════════════════════════════════┐
║  [ 퍼즐 제목 ]                               [×] 닫기 ║
╠═══════════════════════════════════════════════════════╣
║                                                       ║
║              [ 퍼즐 컨텐츠 영역 ]                     ║
║                                                       ║
╠═══════════════════════════════════════════════════════╣
║  힌트: [힌트 텍스트]                    [확인] [취소] ║
└═══════════════════════════════════════════════════════┘
```

- **팝업 크기:** 가변. 최소 480×320px, 최대 960×640px.
- **프레임 스타일:** 이중선 테두리 (`═` 스타일 연출) — 사내 결재 서류 프레임 참조
- **배경:** `#F0EFEA`
- **제목 바:** `#1C3557` (레거시 네이비), 흰 텍스트, 높이 40px
- **하단 버튼 영역:** `#E8E8E2` 배경으로 분리된 액션 존

### 7-2. 입력창 (LineEdit) 스타일

- 배경: `#FFFFFF`, 테두리: `#8A8F99` 1px solid, 포커스 시 `#3A5F8A` 2px
- 폰트: D2Coding 22px (숫자 입력용) / 나눔고딕 18px (텍스트 입력용)
- 높이: 44px (클릭 영역 확보)
- 입력값 최대 표시 영역 중앙 정렬
- 오답 시: 배경 순간 `#C0392B` 플래시 → 0.3초 후 복귀

### 7-3. 버튼 스타일 체계

| 버튼 타입 | 배경 | 텍스트 | 테두리 | 사용처 |
|----------|------|--------|--------|--------|
| **Primary** | `#3A5F8A` | 흰색 | 없음 | 확인, 제출, 클리어 |
| **Secondary** | `#F0EFEA` | `#1C3557` | `#8A8F99` 1px | 취소, 닫기, 힌트 |
| **Danger** | `#C0392B` | 흰색 | 없음 | 위험 선택지, 야근 수락 |
| **Hidden** | `#1A1A1A` | `#D4A017` | `#D4A017` 1px | 히든 루트 전용 |
| **Disabled** | `#E0E0E0` | `#AAAAAA` | 없음 | 비활성 조건 |

- **최소 크기:** 120×44px (텍스트 버튼), 44×44px (아이콘 버튼)
- **호버 상태:** 10% 밝기 변화 + 커서 포인터
- **클릭 상태:** 3px 눌림 효과 (Y축 +2px 이동 + 약간 어두워짐)

### 8-2. 스타일 명세

- **팝업 위치:** 화면 하단 1/3 고정 (씬 배경 가리지 않도록)
- **대화창 배경:** `#F0EFEA` 반투명 (alpha 0.95), 테두리 `#2C2C2C` 2px
- **NPC 이름 영역:** `#1C3557` 배경, 흰 텍스트. "과장님", "인사팀" 등 직함만 표시
- **대화 텍스트:** 나눔고딕 18px, `#1A1A1A`, 줄간격 1.6
- **타이핑 애니메이션:** 한 글자씩 출력 (0.04초/글자). 클릭 시 즉시 전체 출력.

### 8-3. 선택지 버튼 배치

- **배치:** 세로 스택 (`VBoxContainer`), 간격 8px
- **버튼 높이:** 52px (세로 여유 확보)
- **기본 스타일:** Secondary 버튼 (흰 배경, 네이비 텍스트, 회색 테두리)
- **호버 시:** 좌측에 `▶` 포인터 마커 출현 + 배경 `#E8EFF5` 전환
- **분위기 차별화:**
  - 순응 계열 선택지: 일반 Secondary 스타일
  - 저항 계열 선택지: 텍스트 색 `#8A3A3A` (어두운 붉은빛)
  - 히든 트리거 선택지: 텍스트 기울임 + `*` 접두사 (예: `* 이게 맞나...`)
- **선택 후:** 선택한 버튼만 남기고 나머지 페이드 아웃 → 결과 대사 출력

### 9-2. 엔딩별 디자인 명세

#### 엔딩 1: 완벽한 직원
- **배경색:** `#F0EFEA` (기본 사무실) → 점점 밝아지는 흰색
- **색조:** 차갑고 깨끗한 흰색. 과도하게 밝음 — 불쾌할 정도로
- **타이틀 스타일:** `#1C3557` 볼드, 28px. 레이아웃: 중앙 정렬
- **일러스트 방향:** 텅 빈 사무실에 혼자 남은 책상, 모니터만 빛남
- **마지막 텍스트:** `"내일 08:50 회의가 등록되었습니다."` — 회색 소문자 느낌
- **특이점:** 텍스트가 화면 중앙에 홀로 떠있는 공허한 배치. BGM 없음.

#### 엔딩 2: 정상 퇴근
- **배경색:** 어두운 남색 (`#1A2A4A`) → 오른쪽 하단에 창문 빛
- **색조:** 저녁 하늘 느낌. 회사 밖은 어두운 파란색
- **타이틀 스타일:** 나눔바른고딕 Regular, `#A8C4E0`, 가벼운 무게
- **일러스트 방향:** 사무실 창문 너머 도시 야경. 텅 빈 책상에 가방
- **마지막 텍스트:** `"평범한 저녁이 시작되었다."` — 온화하고 담담
- **특이점:** 게임 내에서 가장 "정상적인" 색감. 안도감.

#### 엔딩 3: 야근
- **배경색:** `#2C2C2C` 어두운 회색. 모니터 빛만 남음
- **색조:** 형광등도 꺼진 어두운 사무실. 모니터 블루빛만
- **타이틀 스타일:** `#C0392B` 굵은 고딕, 24px. 깜빡임 애니메이션
- **일러스트 방향:** 빈 사무실에 불 꺼진 상태, 화면만 빛남. 시계는 밤 11시
- **마지막 텍스트:** `"조금만 더 하면 끝납니다."` — 빨간색, D2Coding 폰트
- **특이점:** 텍스트가 끝나지 않는 로딩 바처럼 반복될 것 같은 느낌

#### 엔딩 4: 칼퇴 (히든)
- **배경색:** 비상계단 어둠 → 문이 열리며 외부 노란 가로등 빛
- **색조:** 극적인 명암 대비. 어두운 내부 vs 따뜻한 외부
- **타이틀 스타일:** `#D4A017` 황색, 약간 기울임. 비공식적인 느낌
- **일러스트 방향:** 열린 비상구 문, 바깥 빛이 계단을 비춤
- **마지막 텍스트:** `"생각보다 문은 쉽게 열렸다."` — 여백 많이, 폰트 작게
- **특이점:** 타이틀 앞에 `[히든 엔딩]` 뱃지 표시 (`#D4A017` 박스)

#### 엔딩 5: 퇴사 (히든)
- **배경색:** 완전한 검정 `#0A0A0A` → 텍스트만 떠있음
- **색조:** 아무것도 없음. 터미널 화면
- **타이틀 스타일:** D2Coding 폰트, `#27AE60` 초록색 (터미널 텍스트)
- **일러스트 방향:** 없음. 배경 순수 검정, 터미널 커서 깜빡임
- **마지막 텍스트:** `"승인은 필요 없었다."` — D2Coding, 흰색, 커서 `_` 뒤에 블링크
- **특이점:** 가장 미니멀. 텍스트 한 줄 + 커서만. 영화 스크롤 크레딧처럼 느림

#### 엔딩 6: 회사의 일부
- **배경색:** `#F0EFEA` 사무실 기본 — 처음과 완전히 동일
- **색조:** 변화 없음이 핵심 연출
- **타이틀 스타일:** `#8A8F99` 회색 텍스트, 작은 크기 (22px). 묻혀있는 느낌
- **일러스트 방향:** 사무실 배경 그대로. 플레이어 책상에 이름패가 생겨있음
- **마지막 텍스트:** `"플레이어가 NPC 직원이 되었습니다."` — 시스템 메시지 폰트
- **특이점:** UI 상단 HUD 바에 플레이어 이름이 "직원 #008" 같은 번호로 바뀜. 가장 섬뜩한 엔딩.

| 전환 상황 | 효과 | 방식 |
|----------|------|------|
| 일반 씬 이동 | 문 열리고 닫히는 검정 페이드 | 0.3초 페이드인/아웃 |

| 오답 / 실패 | 화면 빨간 플래시 | 0.1초 `#C0392B` 오버레이 후 복귀 |
| 히든 루트 진입 | 전체 화면 서서히 어두워짐 | 1.5초 블랙아웃 |
| 엔딩 진입 | 씬별 고유 효과 (위 9번 참조) | 엔딩마다 개별 처리 |

## 11. 인터랙션 오브젝트 시각적 피드백

### 클릭 가능 오브젝트 강조 방식

- **기본 상태:** 오브젝트는 씬 배경에 자연스럽게 혼합
- **커서 오버:** 테두리 `#3A5F8A` 2px 점선 출현 + 오브젝트 1.02배 미세 확대
- **오브젝트 위 툴팁:** 오브젝트 상단에 작은 레이블 출현 (`#F0EFEA` 배경, 14px)
  - 예: `"커피 영수증"`, `"복사기"`, `"냉장고"`
- **이미 조사한 오브젝트:** 테두리 회색 점선 (재조사 가능 표시)
- **비활성 오브젝트 (조건 미충족):** 툴팁 없음, 커서 포인터 없음

### 인터랙션 키 안내 (선택 사항)

- 씬 최초 진입 시 하단에 0.5초 페이드인으로 "클릭하여 조사" 안내 텍스트 표시
- 3초 후 자동 페이드아웃
